# AfterWord Frontend Documentation

Welcome to the AfterWord frontend documentation. This repository contains the React Native mobile application built with Expo and NativeWind.

## Available Documentation

- **[Architecture & Tech Stack](./architecture.md)**: Details on the Expo Router setup, NativeWind styling, React Query data fetching, Zustand state management, and Supabase integration.
- **[Features Overview](./features.md)**: A breakdown of the core screens and functionality available in the app (Home, Library, Highlights, Semantic Search, and Upload).

## Getting Started

To run the project locally:

```bash
cd afterword-fe
npm install
npx expo start
```

Press `i` to open the iOS simulator, or `a` to open the Android emulator. Ensure you have your `.env` configured with your local or remote Supabase keys.
